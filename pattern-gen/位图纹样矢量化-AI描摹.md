# 位图纹样转矢量路径 —— Illustrator 图像描摹指南

> 配套「纹样生成器」使用。生成器导入的纹样、以及你收藏的位图纹样图,本质都是**位图**;导出的 SVG 里它们是嵌入图片、不是矢量路径。想在 AI 里当**可编辑路径**用,就靠这一步描摹。
> 适用:细密 / 彩色的游戏 UI 纹样(唐草纹、国风花纹这类)。

## 什么时候用
- 想在 Illustrator 里**编辑纹样的路径**(改形、改色、拆件、重新组合)。
- 位图纹样太糊、想要**无损缩放**的矢量版。
- 不需要时就别描:只是平铺 / 导出图片用,位图 PNG 就够,描摹反而多此一举。

## 前置一步(让描摹更干净)
先在「纹样生成器」里:**勾「去纯色背景」→ 导出透明 PNG**。
背景先去掉,AI 描摹时就不用跟背景较劲,路径更干净、更少杂点。

## Illustrator 图像描摹步骤

**1. 置入图**
`文件 > 置入`,选中这张 PNG。

**2. 打开描摹面板**
`窗口 > 图像描摹`(Window > Image Trace)。顶部控制栏也有「图像描摹」按钮。

**3. 关键参数**(细密彩色纹样,重点在 颜色数 和 杂色)

| 参数 | 设成 | 为什么 |
|---|---|---|
| 模式 Mode | **彩色 Color** | 保留颜色 |
| 调板 Palette | **限制 Limited** | 手动控制颜色数 |
| 颜色数 Colors | **先试 6～16** | 越少路径越简洁;颜色不多的纹样 8 左右够 |
| ⭐ 杂色 Noise | **调高到 20～25px** | 细密纹样关键 —— 忽略小杂点,不然会炸出一堆碎路径 |
| 路径 Paths | 中等(~50%) | 高=更贴合但锚点多,低=更简化 |
| 边角 Corners | 中等 | |
| 忽略白色 Ignore White | 勾上(若还有白底) | 顺手去白 |

> 先勾 **「预览 Preview」**,边调边看效果再定。

**4. 变成真路径 —— 「扩展 Expand」**
参数满意后,点控制栏 **「扩展」**(或 `对象 > 扩展`)。
**这一步是关键**:位图到这里才真正变成**可编辑的矢量路径组**。扩展前它还只是"描摹预览"。

**5. 收拾干净**(可选,但推荐)
- `对象 > 路径 > 简化`:减少锚点,曲线更顺、文件更小。
- 右键 `取消编组` → 用「魔棒」或 `选择 > 相同 > 填充颜色` 选同色块 → 需要的话用「路径查找器 Pathfinder」合并。

## 三下要诀
**颜色调少 + 杂色调高 + 描摹后简化路径** —— 这三下能让细密纹样描出来不至于路径爆炸。

## 描摹之后能干嘛
- **改色**:选中路径直接换填色,做同一纹样的多个配色版。
- **拆件重组**:把纹样的元素拆出来,变形 / 重新拼(呼应你「形态转化」的做法)。
- **给引擎**:干净的矢量可再导 SVG,或在 AI 里精修后导高清 PNG。

## 现实预期(诚实)
描摹是「按像素猜路径」,不是还原原设计的干净路径:
- **扁平、颜色分明**的图案 → 描摹效果好。
- **渐变、极细线条、照片质感** → 路径会多、可能失真,别期待完美。
- 真要极致干净,还是得手动重绘;描摹是"快速拿到可编辑矢量"的折中。
