# 切图工具（cutout）

两个搭配用的小工具，解决「切图去透明边」和「9-slice 九宫格」这两件反复耗时间的琐事。

---

## 1. 批量裁透明边 —— `trim_alpha.py` / `拖我-裁透明边.bat`

把 PNG/WebP/TGA 四周多余的透明像素裁掉，让每张图紧贴内容边缘。

### 最简单的用法
把「一个文件夹」或「一堆图片」**拖到 `拖我-裁透明边.bat` 图标上**，松手即跑。
结果默认另存到每张图同目录下的 **`_trimmed`** 子文件夹，**不会动原图**。

### 命令行用法（要调参数时）
```
python trim_alpha.py <文件或文件夹> [选项]
```
| 选项 | 作用 |
|---|---|
| `--pad N` | 裁完后四周各留 N 像素透明边（默认 0，紧贴内容） |
| `--threshold N` | alpha ≤ N 的像素算透明（默认 0；边缘有半透明羽化想一起裁掉就调大，如 10） |
| `--out DIR` | 指定输出目录 |
| `--inplace` | 覆盖原图（谨慎，默认不覆盖） |
| `--no-recursive` | 拖文件夹时不进子文件夹（默认递归） |
| `--meta` | 额外输出 `_trim_meta.csv`，记录每张的原尺寸/裁后尺寸/裁掉的偏移（还原锚点用） |

会自动跳过：整张全透明的、没有透明通道的、已经紧贴边缘的。

## 2. 9-slice 预览 —— `9-slice预览.html`

**双击直接用浏览器打开**（零安装）。做拉伸不变形的边框/面板（圆角、描边不被拉糊）。

- 打开就有一张示例图；点「载入图片…」或直接把图拖进窗口换成自己的。
- **拖动图上的四条金线**，或在左边填「左右上下」边距，定九宫格分割位置。
- 拖「预览目标尺寸」滑块，实时看拉伸效果。
- **复制边距数值**：一键拿到四个数（含 Unity / CSS 写法），填进引擎。
- **导出九块 PNG**：自研引擎要九张图时用，后缀 `tl/tc/tr/ml/mc/mr/bl/bc/br`。

> 边距怎么填：Unity Sprite Border = `左,下,右,上`；CSS = `border-image-slice: 上 右 下 左`。
