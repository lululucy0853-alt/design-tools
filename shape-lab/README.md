# 形状组合器(shape-lab)

**把"必须手动做出来才知道好不好看"这一步的成本压掉。**

灰模刚变成形状那一步最贵:形状之间的组合只有真做出来才看得出成不成立,做一次几十分钟,试五个就是一下午。这个工具让你一屏同时看 12 个变体,锁住对的、重掷其余的。

不联网、不上传,双击 `形状组合器.html` 就开。

## 怎么用

| 步 | 做什么 |
|---|---|
| 1 | 点**重掷 12 个**,扫一眼 |
| 2 | 某一轴对了(比如转角就要切角),点那一轴的**「锁」**,或直接点具体选项(会自动上锁) |
| 3 | 再重掷 —— 锁住的不变,只换其余的 |
| 4 | 点中意的那格 → 右栏出现**同一套语言套在五种件上**:主按钮 / 返回键 / 长条框 / 方形道具格 / 标题条 |
| 5 | **导出选中 SVG**(五个件都在一张里)或**导出这一屏**(12 个变体拼版),拖进 PS / AI 继续画 |

## 参数轴 = wiki 里那套

对应 [[03_视觉语言_新风格推导法]] 的造型三步,外加一轴转角(来自「怎么连接」三问):

| 轴 | 取值 |
|---|---|
| 轮廓 · 基底 | 方 / 圆 / 三角 / 六边 |
| 轮廓 · 转角 | 直角 / 圆角 / 切角 / 内凹 / 阶梯 |
| 轮廓 · 边缘(材料感) | 规则 / 轻微不规则 / 强不规则 |
| 分割 | 无 / 横分 / 纵分 / 顶饰带 / 内嵌框 / 斜分 |
| 填充 | 平涂 / 渐变 / 边缘发光 / 网点 / 斜线 / 空 |
| 转角装饰(怎么连接) | 无 / 铆钉 / 包角 / 缺口 / 缠绕 |

## ⭐ 内置的四条硬约束

工具生成的**每一个**变体都自动满足:

| | 为什么 |
|---|---|
| 轮廓封闭 | 有边界才能被"按" |
| 与背景有明度差 | 浮起来才像能动 |
| 内部留出文字位 | 暗示"这里有内容" |
| 同类成组重复(每格画 3 个) | 重复 = 这是一类控件 |

这四条决定"像不像能点的东西",**和世界观无关**。工具替你守住,你只需要判断**好不好看**和**符不符合世界观**——三个约束降到两个。

## 一条使用建议

右栏那五个件里,**盯住「返回键」**。它是最小的元件,一套形状语言如果在它身上认不出来了,说明这套语言撑不住小尺寸——这时候在主按钮上再好看也没用。

## 已验证(2026-08-25)

12 格变体互不相同 · 锁定轴后重掷只换其余 · 五种件渲染正常 · 两种导出都是合法 SVG(单个 8KB / 整屏 19KB,DOMParser 解析无错)。

**没验证的**:实际画稿里好不好用——这要你试过才知道。目前是灰模级配色(浅灰 + 深描边),刻意不上色,因为这一步该只看形。
