# 策划案看板(spec-reader)

把一份游戏 UI 策划案,变成**一个能双击打开的看板**——按游戏 UI 制作的 5 层流程排:第 1 层给因(业务目标 / 用户任务 / 使用频次 + 装什么 + 排优先级),第 2 层给果(视觉层级高 / 中 / 低 + 视线路径 + 主 CTA),问题按「卡住第几层」归位。

它不做"总结策划案"——总结是把已有的话说短,它做的是**指出策划案里没说的话**:漏掉的界面、没写的状态、必须开工前问清的边界。

## 文件

| 文件 | 是什么 |
|---|---|
| `board-template.html` | **模板,唯一一份**。要改长相就改它,别复制副本 |
| `build.py` | 数据 + 模板 → 看板 HTML |
| `data-*.js` | 每份策划案的分析数据(不入库,见下方隐私) |

## 用法

```bash
python build.py "data-示例.js" "示例-看板.html"
```

日常不用手动跑。配套的 `game-ui-spec-reader` skill(装在 `~/.claude/skills/`)会读策划案、写数据、调用这个脚本、把看板交出来。

## 看板里能做什么

| | |
|---|---|
| 五层步进条 | 一眼看出**卡在第几层**,点哪层跳哪层 |
| 界面卡 | 点开是这屏的因 + 装什么 + **排优先级 ①②③(颜色依次变浅)** + 主 CTA |
| 红色虚线卡 | 策划案里没单独列、但实际要做的界面 |
| 问题清单 | 每条标**卡住第几层**;卡第 1 层的标红 = 必须先问。每组一键复制成消息 |
| 打勾 | 问完一条勾一条,存本地,关了再开还在 |
| Ctrl+P | 直接打成 PDF |

不联网、不上传。

## 数据格式

见 skill 的 `references/board-schema.md`。简要结构:

```js
{
  meta:{title,src,date,tags:[]},
  steps:[{nm,st,block?}, ×5],          // 五层步进条
  verdict:{lab,head,why,blockers:[]},  // 结论 + 卡死的问题
  L1:{sub,constraint,screens:[…],workload},   // 架构(因)
  L2:{sub,items:[…]},                          // 引导(果)
  L3:{…}, L4:{gaps:[…]}, L5:{…},
  questions:[{layer,t,im}], self:[], clear:[]
}
```

## 🔒 隐私

**策划案分析数据里有真实项目内容,一律不进这个公开仓库。**`data-*.js` 和生成的 `*看板.html` 已在 `.gitignore` 里排除。要分享看板给同事,直接发生成出来的那个 HTML 文件,别提交进来。
