# design-tools · 设计工具集

> 王璐的自用设计辅助工具集（私有仓库，自用 + 协作）。纯本地小工具，解决游戏 UI 日常里反复耗时间的琐事。

## 工具一览

### 🎨 纹样生成器 · `pattern-gen/纹样生成器.html`
双击浏览器打开。参数化生成装饰纹样，SVG 矢量原生输出、零依赖、离线可用。
- **27 种纹样 / 5 族**：中国 · 现代简约 · 科技 · 卡通 · 欧式/西幻（鸢尾百合/莨苕卷草/盾徽/皇冠/哥特尖拱/玫瑰窗）
- **9 种组合形式** × **6 种材质** × 多组配色（含皇家金蓝 / 纹章红金）
- **自定义**：导入自己的图形当纹样 / 从连续大图提取最小重复单元 / 去纯色背景（容差可实时调）/ 我的预设 / 自定义色板 —— 全部浏览器本地保存
- **线框 ↔ 实心** 切换、**360° 旋转**；组合选「单张放大」+ 透明底可检查抠图
- **导出**：SVG（内置纹样是可编辑矢量路径）/ PNG，可导出透明背景
- 配套文档：[位图纹样矢量化-AI描摹.md](pattern-gen/位图纹样矢量化-AI描摹.md)（把位图纹样在 Illustrator 里转成矢量路径的方法）

### 📄 md2pdf · `md2pdf/`
Markdown → 带中文字体的 PDF（表格 / 代码块正常显示）。
用法：`node md2pdf/md2html.js <输入.md> <临时.html>`，再用 Edge 无头打印成 PDF。

### 📥 capture · `capture.py` / `capture.js`
抓取网页标题等元信息、收进第二大脑 `inbox/` 的小脚本（配合 learning 知识库用）。
